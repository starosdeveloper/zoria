# Журнал решений

Черновик для `DECISIONS.md` финальной сдачи (оценивание, раздел 10): в каждой записи — что выбрано, какую альтернативу рассматривали, чего это стоит, где в коде. Строки в коде проставляются перед сдачей.

## 1. Одна печать — один источник правды об эфире

- **Выбрано.** Любой конверт, где бы он ни пришёл (`/ether`, `/ether/roll`, 503 с другого маршрута), идёт через `EtherMonitor.ingest`. Фаза берётся только из подписанного кадра с максимальным `at`.
- **Альтернатива.** Держать фазу для каждого маршрута отдельно или верить `/public/config`.
- **Цена.** Одна проверка Ed25519 на каждый ответ до просвета. Все выводы «открыто/закрыто» сходятся в одной точке.
- **Где.** `packages/core/src/ether/monitor.ts`, `ether/state.ts`.

## 2. Поправка часов — максимум нижних оценок

- **Выбрано.** `at` кадра ставится до отправки, а помеха-задержка держит кадр 2–8 с. Поэтому `at − время получения` — всегда нижняя оценка сдвига часов, и берём максимум за последние 24 кадра.
- **Альтернатива.** Среднее или медиана с поправкой на половину RTT.
- **Цена.** Массив из 24 чисел. Задержанные кадры отсчёт не сбивают.
- **Где.** `packages/core/src/ether/state.ts` (`sampleClock`).

## 3. Регистрация без второго аккаунта

- **Выбрано.** Автомат: при потерянном ответе или 409 сначала вход с теми же данными. 200 — аккаунт наш; 401 — повторить регистрацию (после 409 — отказ). 429 `authentication-busy` — ждать `Retry-After`, это не нарушение.
- **Альтернатива.** Повторять регистрацию с backoff.
- **Цена.** Один лишний запрос входа на каждый сбой. Второй аккаунт означает снятие с конкурса (13.6), так что платить есть за что.
- **Где.** `packages/core/src/flows/register.ts`.

## 4. Локальное ведро строже серверного

- **Выбрано.** 12 токенов вместо 20, пополнение раз в 3 с. После `429 jammed` — полная тишина, сохранённая в хранилище.
- **Альтернатива.** Полагаться только на интервалы опроса.
- **Цена.** Всплеск запросов упирается в очередь. Зато клиент в одной вкладке, наблюдатель и соседи по NAT не выбивают адрес.
- **Где.** `packages/core/src/net/gate.ts`.

## Ограничения (кандидаты в раздел 3)

- Отпечаток ключа печати боевого сервера не закреплён, пока его не опубликуют. До этого ключ проверяется только на внутреннюю согласованность, и интерфейс об этом предупреждает.
- Мок стенда написан по спецификации; с настоящим стендом его не сверяли.
