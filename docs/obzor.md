# Зоря. Выход на связь

**Зоря** — конкурс, где ваш код играет за вас. Первая неделя уже открыта: вы пишете клиент сети **Зоря.нет** и регистрируетесь с его помощью во время **«просвета»** — окна, которое открывается в заранее не объявленный момент. Дальше — бот, штаб, групповой этап и финал.

**Опубликовано 21.09**

## Коротко

* **Что строить:** клиент сети на **React + TypeScript** в репозитории вашей заявки. Минимум — регистрация, статус доступа к репозиторию, уведомления и части задания ([ТЗ](https://zoria.net/part1/tz/), раздел 1).
* **Когда «просвет»:** начнётся между **24.09, 08:00** и **25.09, 12:00** и продлится как минимум 10 часов. Кто не зарегистрировался во время «просвета», выбывает.
* **Что сделать:** зарегистрироваться во время «просвета», пригласить в репозиторий аккаунт организаторов и положить в корень репозитория файл `.zoria` со своим логином в сети. **Жеребьёвка — 26.09.2026, часть 2 — 28.09.2026.**
* **Контракт:** API `https://zoria.net/api/v1`, учебный стенд `https://stand.zoria.net/api/v1`, [OpenAPI](https://zoria.net/part1/openapi/).
* **Остальная часть задания:** части 2–4 выдаются участникам в личном кабинете сети, каждая в свой срок. На сайте их нет.

## Порядок чтения

**Легенда** (около десяти минут) → **ТЗ части 1** → **спецификация клиента**.

Оценивание и календарь — справочная информация: к ним возвращаются, чтобы посмотреть баллы и сроки.

## Какой документ главный

Одна тема — один документ, остальные ссылаются на него:

| Тема                                                                 | Документ                                                |
| -------------------------------------------------------------------- | ------------------------------------------------------- |
| **Поля, форматы, коды ответов**                                      | [OpenAPI](https://zoria.net/part1/openapi/)             |
| **Поведение сервера и клиента**                                      | [спецификация клиента](https://zoria.net/part1/client/) |
| **Условия допуска к части 1**                                        | [ТЗ части 1](https://zoria.net/part1/tz/)               |
| **Сроки**                                                            | [календарь](https://zoria.net/calendar/)                |
| **Баллы, санкции, апелляции**                                        | [оценивание](https://zoria.net/scoring/)                |
| **Числа, которые система оценивания оставила в качестве дополнений** | [реестр дополнений](https://zoria.net/addenda/)         |

Пакет выпускается на **русском и украинском языках**. В случае расхождения версий действующей считается **русская версия**.

Контракт OpenAPI и примеры кода из пакета распространяются по лицензии **MIT**: их можно копировать в свой клиент.
