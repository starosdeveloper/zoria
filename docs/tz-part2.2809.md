## 2. Что должно работать до конца части 2

| ID | Требование | Как проверить |
| --- | --- | --- |
| P2-01 | Бот лежит в вашем репозитории из части 1 и собирается командами из его README | новый checkout, `npm ci`, `npm run build` |
| P2-02 | Бот присягает узлу за `ZARIA_URL` и `ZARIA_TOKEN`, играет партию до конца без закрытий 4001–4004 | `npm run play -- --fast`: у `pack.json` нет `absent` на вашем месте, бот печатает конец партии `end` |
| P2-03 | Бот сам рвет провод, если хеш двигателя узла не совпадает с ожидаемым | `npm run play -- --fast --ticks 60 --bot "ZARIA_ENGINE=<64 знака a> node dist/main.js"`: бот не входит ни в одну партию и печатает причину, узел пишет «без присяги» |
| P2-04 | Бот сам ведет слот: отвечает вовремя и подает принятую команду хотя бы раз в 6 тактов | `npm run play` в темпе 500 мс: нет строчек «ваш слот вел приказ» |
| P2-05 | Бот пишет дневник веры в файл `ZARIA_BELIEF`: строка NDJSON на такт в форме `BeliefFrame` | после пакета `belief-1.ndjson` … `belief-3.ndjson` непустые, строка разбирается как `BeliefFrame` |
| P2-06 | `nakaz.yaml` лежит в каталоге бота и проходит три ступени линтера | `npm run lint:nakaz` завершается с кодом 0 |
| P2-07 | Секрета реестра нет в репозитории | в истории репозитория нет значений `token` и `auth` из ответа hub; `.npmrc` содержит только ссылку `${ZORIA_NPM_AUTH}` |
| P2-08 | Бот написан на TypeScript или JavaScript и работает в Node.js 24 или новее, как шаблон | исходный код бота — `.ts`, `.js`, `.mjs`, `.cjs`; поле `zaria.bot` в `package.json` запускает бота командой `node` |

Шаблон бота (`npx @zoria/kit init bot`) выполняет P2-01, P2-02, P2-03, P2-05, P2-06 и P2-08
с первой минуты. P2-04 — работа вашей стратегии: заглушка шаблона молчит, когда ей нечего
скомандовать.

Язык бота — TypeScript или JavaScript, рантайм — Node.js 24 или новее, как в шаблоне (P2-08,
`01-rules.md`, 3.1). Проверки кода в оценке работают только с TypeScript и JavaScript, и бот
на другом языке не проходит ворота допуска (часть 4). Собственного клиента провода вместо
`connectBot` писать можно, на тех же языках. Команду запуска бота `npm run play` задает поле
`zaria.bot` в `package.json` каталога бота.

ИИ-инструменты при работе над ботом и приказом разрешены.

## 3. Как начать

```bash
curl -fsS -H "Authorization: Bearer $ZORIA_HUB_TOKEN" https://zoria.net/api/v1/me/registry-token > ~/.zoria-registry.json
export ZORIA_NPM_AUTH=$(node -p "require(process.env.HOME + '/.zoria-registry.json').auth")
node -p "require(process.env.HOME + '/.zoria-registry.json').npmrc" > .npmrc
npx @zoria/kit init bot
cd bot && npm install
npm run play -- --fast
```

`$ZORIA_HUB_TOKEN` — свежий токен входа в hub: вход действует сутки. Просроченный токен —
`curl` завершается ошибкой 401, и дальше ничего не работает: войдите снова и повторите.
Объяснение к каждому шагу — `02-path.md`.
