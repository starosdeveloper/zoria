# Бот Зорі — пресет «жатва»

Бот частини 2 на шаблоні `@zoria/kit`. Документи частини 2 - у пакеті
`@zoria/kit`: `npx zaria-kit docs` друкує, де вони лежать. Розбір рішень,
карта модулів і обмеження - `DECISIONS.md` у корені репозиторію.

## Збирання і перевірка

| Команда | Що робить |
|---|---|
| `npm ci` | ставить пакети `@zoria/*` з реєстру за `package-lock.json` (потрібна змінна `ZORIA_NPM_AUTH`, `02-path.md`) |
| `npm run build` | збирає бота в `dist/` |
| `npm test` | збирає і проганяє перевірки (`node --test`), без мережі, кілька секунд |
| `npm run lint:nakaz` | три ступені лінтера наказу |
| `npm run check` | збирання, перевірки і лінтер наказу разом |

## Гра

| Команда | Що робить |
|---|---|
| `npm run play -- --fast` | збирає і грає локальний пакет: три партії, ваш бот у вершинах A, B, C |
| `npm run play` | те саме в темпі 500 мс на такт, як у заліку |
| `npm run play -- --fast --provoke N` | вузол-провокатор рівня 1, 2 або 3 (`06-local-pack.md`) |
| `npx zaria-kit replay records/<пакет>` | відтворити запис і звірити рахунок |
| `npx zaria-kit version` | хеш рушія і версії пакетів |

Прапорці пакета: `--seed`, `--packs`, `--ticks`, `--vs`, `--bot`; усі -
`npx zaria-kit help`.

## Заміри

Усі під `nice` і з одним потоком V8, щоб замір не забирав машину.

| Команда | Що робить |
|---|---|
| `npm run spar [-- жереб ...]` | спаринг в одному процесі проти суперників локального пакета і базова лінія «рівний»; `SPAR_RIVALS`, `SPAR_DIALS`, `SPAR_WHY=1` (плани і відмови), `SPAR_TIME=1` (куди йде час Ткачів, облоги, тарани) |
| `npm run tourney [-- жереб ...]` | локальний турнір: п'ять складів × жереби, середня частка; `TOURNEY_SELF=1` - суперники «жатва» за замовчуванням |
| `npm run mutate:part 'dist/<файл>.js:<рядки>'` | мутаційне тестування шматком (`stryker.config.json`) |
| `node episode.js <match-N.runlog> <A\|B\|C> <від> <до> [--md]` | епізод партії: журнал відтворюється головою, команди звіряються байт у байт; `--md` - чернетка `EPISODE.md` |
| `node crown.js` | граф голок, що горять, наприкінці партії: цикли і обхват для вінця |

## Файли

| Файл | Що в ньому |
|---|---|
| `src/main.ts` | провід: присяга, повтор входу, перевірка пінів, оточення |
| `src/seat.ts` | стан голови: знімок для службового порту, зміна пресета, щоденник віри, рядок кінця партії, запис кидків |
| `src/strategy.ts` | яка голова веде слот: «жатва» (типово) або дзеркало архетипу SDK за `ZARIA_PRESET` |
| `src/harvest.ts` | пресет «жатва»: уся політика - плани машин, бюджет каналу, верф, ставки, сторож |
| `src/valley.ts` | статика партії: гексова арифметика, маніфест, відстані й дорога через оракул |
| `src/numbers.ts` | числа світу з маніфесту за іменами; пропуск - відмова грати |
| `src/belief.ts` | щоденник віри: кадр NDJSON на такт |
| `src/jitter.ts` | пауза повтору першого входу |
| `src/status.ts` | внутрішній службовий порт голови (`STATUS_PORT`); його читає стек |
| `nakaz.yaml` | грамота «жатва»: веде слот, коли бот мовчить або його процес помер |
| `.npmrc` | реєстр `@zoria` і посилання на змінну `ZORIA_NPM_AUTH`; секрету у файлі немає |

`records/` - записи локальних пакетів; у репозиторій не комітиться.

Мова виводу команд - українська: її задає поле `zaria.lang` у `package.json`
(`uk` або `en`). Разово - прапорець `--lang` або змінна `ZARIA_LANG`.

## Службовий порт

`STATUS_PORT` вмикає внутрішній порт голови: `GET /state` віддає знімок
проводу (такт, кадри, лічильники, щоденник), `POST /preset` змінює пресет
між партіями. Локальному пакету він не потрібен і типово вимкнений;
вмикає його стек частини 4 (`npx zaria-kit init stack`), і з цього знімка
його control-plane збирає `/health` і `/metrics` службового контракту.
З увімкненим портом голова не виходить після партії, а лишається жива і
відповідає про її кінець.
